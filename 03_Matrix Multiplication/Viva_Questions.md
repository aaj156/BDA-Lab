# Hadoop MapReduce Matrix Multiplication – Viva Questions with Answers

## Basic Concepts

### 1. What is Hadoop?
**Answer:** Hadoop is an open-source framework for distributed storage (HDFS) and parallel processing (MapReduce) of large datasets.

### 2. What is HDFS?
**Answer:** Hadoop Distributed File System (HDFS) stores large files by dividing them into blocks distributed across DataNodes.

### 3. What is MapReduce?
**Answer:** A programming model consisting of a Mapper phase, Shuffle & Sort phase, and Reducer phase for distributed data processing.

### 4. What is the role of the Mapper?
**Answer:** Reads input records and generates intermediate key-value pairs.

### 5. What is the role of the Reducer?
**Answer:** Receives grouped intermediate values and produces the final output.

### 6. What is the purpose of Shuffle and Sort?
**Answer:** It groups values having the same key before they reach the Reducer.

### 7. What is a JAR file?
**Answer:** A Java Archive containing compiled class files required to run the Hadoop application.

### 8. Why do we create MatrixMultiply.jar?
**Answer:** Hadoop executes the application from this JAR.

### 9. Why is the output directory deleted before execution?
**Answer:** Hadoop does not overwrite an existing output directory.

### 10. What is part-r-00000?
**Answer:** The reducer output file generated by Hadoop.

## Matrix Multiplication

### 11. What is the input format?
**Answer:** `Matrix,row,column,value`

### 12. Why are matrices tagged as A and B?
**Answer:** To distinguish elements belonging to different matrices.

### 13. What condition is required for matrix multiplication?
**Answer:** Columns of Matrix A must equal rows of Matrix B.

### 14. How is one output element calculated?
**Answer:** By multiplying corresponding row and column elements and summing the products.

### 15. What is the expected output for the sample matrices?
**Answer:**
```
17 23
39 53
```
